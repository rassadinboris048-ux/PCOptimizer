# PCOptimizer

Тёмный неоновый оптимизатор и монитор для Windows: показывает, что происходит с железом,
чистит мусор, приводит систему в порядок и помогает выжать максимум в играх.

Написан на C# (.NET 10), интерфейс — HTML/CSS/JS поверх WebView2.
.NET внутри установщика, отдельно ставить его не нужно.

---

## Что умеет

### Мониторинг
- Загрузка процессора: общая и по каждому потоку, частота, температура
- Видеокарта: загрузка, температура, видеопамять, частота
- Оперативная и видеопамять — занято и всего
- График за последние 60 секунд
- Мини-оверлей на рабочем столе: процессор, видеокарта, температура, память
- Оверлей поверх игры с FPS (считает RivaTuner Statistics Server)

### Очистка
- 12 точек: временные файлы, корзина, кэш браузеров, логи Windows, дампы памяти,
  эскизы, кэш шейдеров видеокарты и другое
- Сначала показывает, сколько места освободится
- Занятые и защищённые файлы пропускаются, а не ломаются

### Оптимизация
- Авто-оптимизация в один клик: точка восстановления, схема питания, визуальные эффекты,
  контроль памяти, фоновые приложения, чистка
- Службы Windows, автозагрузка и фоновые приложения — с пометками, что безопасно
- Возврат изменённых настроек обратно

### Игры
- Библиотека Steam и запуск игр прямо из программы
- Турбо-режим: приоритет игры, освобождение памяти, отключение Game Bar
- Профили под конкретные игры
- Онлайн-игры и античиты не трогаются вообще

### Мой ПК
- Сама определяет процессор, видеокарту, память, диски и версию Windows
- Подстраивается под железо: на SSD не предлагает дефрагментацию, на слабом процессоре
  упрощает анимации, при малом объёме памяти чистит её агрессивнее
- Обслуживание дисков: TRIM для SSD, дефрагментация для HDD

### Мелочи
- 7 акцентных цветов интерфейса, тёмная и светлая темы
- Значок в трее, горячие клавиши, счётчик «сколько сэкономил»
- Настройки хранятся в `settings.json` рядом с программой

## Установка

1. Скачай **`PCOptimizer_Setup.exe`** из раздела [Releases](../../releases).
2. Запусти файл. Windows покажет «Windows защитила ваш компьютер» — установщик не подписан
   сертификатом подписи кода (он платный). Нажми **«Подробнее» → «Выполнить в любом случае»**.
3. Мастер предложит папку (по умолчанию `C:\Program Files\PCOptimizer`) и ярлык на рабочем столе.
4. Установка попросит права администратора — они нужны программе для служб и датчиков железа.

Компонент **WebView2**, на котором нарисован интерфейс, установщик поставит сам, если его нет.

**Удаление:** «Пуск» → «PCOptimizer» → «Удалить PCOptimizer», либо через
«Установка и удаление программ». Вместе с программой удаляются её настройки и отчёты.

## Чего программа НЕ делает

Это важно, потому что «оптимизаторы» часто ведут себя по-свински:

- не отключает службы, нужные самой Windows
- не трогает онлайн-игры и античиты (Vanguard, Easy Anti-Cheat и подобные)
- не закрывает браузеры и VPN без явного разрешения
- не удаляет ничего за пределами своего списка папок
- не лезет в реестр за пределами известных безопасных ключей
- перед изменениями предлагает создать точку восстановления
- никогда не дефрагментирует SSD — только TRIM

## Сборка из исходников

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download) и Windows.

```powershell
git clone https://github.com/Proso_chelTT/PCOptimizer.git
cd PCOptimizer
dotnet build PCOptimizer.slnx -c Release
```

Запустить как есть (нужен установленный .NET):

```powershell
dotnet run --project PCOptimizer\PCOptimizer.csproj
```

Автономная сборка — с рантаймом внутри, как в установщике:

```powershell
dotnet publish PCOptimizer\PCOptimizer.csproj -c Release -r win-x64 --self-contained true -o publish
```

Собрать установщик (нужен [Inno Setup 6](https://jrsoftware.org/isdl.php)):

```powershell
iscc PCOptimizer.iss
```

### Из чего состоит

| Файл | Зачем |
|---|---|
| `Form1.cs` | окно, опрос железа раз в секунду, все команды из интерфейса |
| `HardwareMonitor.cs` | процессор, память, видеокарта, температура |
| `SystemInfo.cs` | определение железа и подстройка под него |
| `GpuCounters.cs` | загрузка видеокарты через счётчики Windows (для AMD и Intel) |
| `Cleanup.cs` | 12 точек очистки и защита от опасных путей |
| `Optimization.cs` | службы, автозагрузка, питание, точка восстановления |
| `DiskTools.cs` | TRIM для SSD, дефрагментация для HDD |
| `Games.cs`, `GameTools.cs` | игры, процессы, Steam, турбо-режим |
| `Settings.cs`, `Stats.cs` | настройки, журнал действий, счётчик экономии |
| `ui/` | весь интерфейс: HTML, CSS и JavaScript |
